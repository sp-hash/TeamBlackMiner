# Mine Vertcoin with Team Black Miner

## General

The first time you mine Vertcoin, the miner generates the **verthash.dat** file needed for mining. It is about 1.3 GB.

Keep this file in the miner folder so it does not have to be generated again, or point to it with `--verthash-data <path>`.

Vertcoin can be mined on GPUs with 2 GB of memory or more.

## Linux

```bash
./tbminer_hashalot_vtc.sh
```
```bash
./tbminer_miningpoolhub_vtc.sh
```

## Windows

Example scripts:
+ `tbminer_hashalot_vtc.bat`
+ `tbminer_miningpoolhub_vtc.bat`

More pools are in the `VTC` folder in [Launchscripts](Launchscripts). Put in your own Vertcoin wallet address before starting.
